## 最終方向如何形成

早期模型嘗試預測任意正常站在 30 分鐘後是否新失衡。模型能排序風險，但逐快照 Precision 不足以直接派工。事件分析同時發現，許多缺車紅燈只維持一個快照；把每次紅燈都視為同等緊急，容易浪費有限注意力。

因此目前系統改為條件式動態預測：當站點已經是 0 車時，判斷 30 分鐘後是否仍為 0 車。每個後續缺車快照都會重新評估，站點恢復有車後停止追蹤。這個目標更接近營運上「哪些紅燈值得持續處理」的問題。

## 資料邊界

這裡只公開彙整後的報告，不包含主辦方提供的 1～6 月大型原始 CSV，也不包含暫存特徵、虛擬環境或舊輸出資料夾。可攜 Demo 所需的精簡六月特徵與凍結核對資料位於專案 `data/`。
